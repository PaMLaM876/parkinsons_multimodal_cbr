Model Architecture

Three modality-specific encoders feed into a Gated Multimodal Unit (GMU) that dynamically weighs each data source per patient.

Speech CNN + BiLSTM

Processes Log-Mel spectrograms through a 3-layer CNN backbone, then a bidirectional LSTM with temporal attention to focus on diagnostically relevant speech segments.
Conv2d(1→32→64→128) + BN + GELU
↓ MaxPool2d(2×2) × 3
BiLSTM(2-layer, h=128) → 256-d
↓ Bahdanau Temporal Attention
concat(192-d spec + 64-d acoustic)
→ e_speech (256)

MRI 3D CNN

Processes T1-weighted structural brain MRI volumes (96³) through a lightweight 3D CNN to capture neuroanatomical patterns of PD.
Conv3d(1→32, stride=2)
Conv3d(32→64→128→256→512)
↓ stride=2 downsampling each
AdaptiveAvgPool3d(1) → 512-d
FC(512→256) + ReLU + Dropout
→ e_mri (256)

Clinical Deep MLP

Encodes 37-dimensional clinical feature vectors (UPDRS Parts I–IV, MoCA, DaTscan SBR, H&Y staging, demographics) via a deep tabular MLP.
FC(37→128) + BN + GELU + Drop
FC(128→128) + BN + GELU + Drop
FC(128→64)
→ e_clinical (64)

Fusion Gated Multimodal Unit (GMU)

The GMU dynamically learns per-patient gate weights (g₁, g₂, g₃) by examining all three modalities simultaneously via a learned gating network:

1. Project → common 256-d space
2. concat(h_s, h_m, h_c) → FC(768→256) → ReLU → FC(256→3)
3. Mask missing modalities → -∞
4. gates = softmax(logits / T=1.5)
5. Gate floor: min 5% per active modality
6. z = g₁·h_s + g₂·h_m + g₃·h_c → FC → (256)

Classification Head + CBR

Classifier: FC(256→128) → ReLU → Dropout(0.3) → FC(128→2) → Softmax → P(PD), P(HC)

CBR Engine: Fused embedding z is stored in a case library. At inference, the k=5 most similar historical patients ("patient twins") are retrieved via cosine similarity for explainable reasoning.

Training safeguards:

  • Gate entropy regularization (λ=0.1) — prevents modality collapse
  • Modality dropout (20%) — robustness to missing data
  • Class-weighted CrossEntropy — handles PD/HC imbalance
  • Differential learning rates per encoder
  • Gradient clipping (max_norm=1.0)
